# Anime Tracker

A PHP and MySQL website for tracking anime. Users will be able to browse anime,
build a watchlist to track and save which episode they are on. 
An admin can add, edit and delete anime.

## Features
- Register and log in (hashed passwords, sessions)
- Admin-only pages for managing anime
- Personal watchlist with episode tracking
- Search by genre, year and status
- Twig templates, PDO prepared statements

## Setup
1. Run `SQL_Code.sql` in phpMyAdmin
2. Run `composer install`
3. Open `public/index.php` in the browser
